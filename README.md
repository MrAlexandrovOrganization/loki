# Loki

Версия образа задаётся в `makefiles/versions.mk`; `make versions` показывает её.
Make экспортирует значение в Compose. CI вызывает `make config-check`.

- `make config-check` — валидация Compose.
- `make up` / `make down` / `make logs` — управление стеком.

При проверках используйте синтетические настройки и checkout без `.env`.
Запускайте Compose через Make, чтобы не дублировать версию образа.

## Хранение

`loki.yaml` задаёт хранение логов за 15 дней, как у текущего Prometheus.
Compactor удаляет более старые данные асинхронно; после применения сокращённого
срока существующие логи старше 15 дней также подлежат удалению. Этот срок не
задаёт жёсткий лимит размера диска: оставляйте запас для индексов, WAL и
временных данных и контролируйте фактический объём хранилища.

После переноса на WSL порт 3100 остаётся на loopback и доступен агентам через
Tailscale Serve. Сохраняется весь named volume, скопированный после остановки
старого Loki. Автодеплой на прежний server отключён по умолчанию: repository
variable `DEPLOY_ENABLED` включается только после настройки правильного target.
